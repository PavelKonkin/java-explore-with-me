# ПойдемСоМной
Сервис для событий и участия в них.
Сервис позволяет пользователям делиться информацией об интересных событиях и находить компанию единомышленников для участия в этих событиях.
Можно добавлять своё событие, искать интересующие события по датам, описанию, по тому, платное событие или бесплатное.

## Дальнейшая разработка
### Перед тем как начать разработку, у вас должны быть установлены следующие зависимости:
- Java 11
- Apache Maven
- Docker
### Сборка и запуск приложения
- Для сборки запустите из корня
  ```bash
  mvn package
- Для тестов запустите из корня
  ```bash
  mvn test
- Для запуска запустите из корня
  ```bash
  docker-compose up
### Приложение состоит из 2 сервисов:
- сервис статистики, в котором накапливается статистика по количеству запросов к каждому событию
- основной сервис приложения с различной функциональностью для администраторов, зарегистрированных пользователей и гостей
Каждый сервис запускается в своем Docker-контейнере и работает со своей БД, которая также запускается в отдельном Docker-контейнере
- основной сервис запускается на порте 8080, сервис статистики на порте 9090, база данных основного сервиса на порте 6543, база данных сервиса статистики на порте 6542. Если они заняты, нужно сначала завершить друие приложения, которые их занимают.
Если освободить порты нельзя, то нужно изменить порты по умолчанию в docker-compose.yml, а также в файлах настроек сервисов application.yml
#### API приложения описано в файлах json: ewm-main-service-spec.json и ewm-stats-service-spec.json

### Стек приложения: Java, SpringBoot, Hibernate, JUnit, Maven, Docker, PostgreSQL
Хранение данных приложения организовано в БД PostgreSQL.
